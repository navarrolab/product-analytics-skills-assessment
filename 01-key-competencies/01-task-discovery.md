
# 01. Поиск задач (Task Discovery)

## Описание компетенции

Способность самостоятельно выявлять аналитические проблемы и возможности, формулировать задачи и инициировать решения, направленные на улучшение продуктов, бизнес-процессов и эффективности работы команды.

## Ожидания по уровням

| Уровень | Ожидания |
|---|---|
| Junior | Выполняет заранее поставленные задачи. |
| Middle | Самостоятельно находит и инициирует задачи уровня Junior. |
| Senior | Самостоятельно находит и инициирует задачи уровня Middle. |
| Lead | Выявляет сложные аналитические проблемы на уровне кластера или вертикали. |
| Principal | Выявляет стратегические аналитические возможности на уровне всей компании. |

## Мой опыт

### 1. Создание системы аналитической документации (более техническая + GitHub)

**Инициатива:** самостоятельная.

По мере увеличения количества клиентов я выявила необходимость создания единой системы аналитической документации.

Инициировала разработку документации, которая позволяла аналитикам и разработчикам:
- Проверять существующие настройки трекинга.
- Отслеживать изменения, внесённые в систему сбора данных сайта.
- Получать информацию о том, какие события и метрики уже настроены.
- Избегать дублирования задач по настройке трекинга.

### 2. Создание шаблонов отчётов GA4 Exploration для A/B-тестов

**Инициатива:** самостоятельная.

Я обнаружила, что создание стандартных отчётов по A/B-тестам в GA4 Exploration представляет собой повторяющуюся задачу, которую можно делегировать проектным менеджерам.

Разработала переиспользуемые шаблоны отчётов, которые позволяли проектным менеджерам:
- Создавать копию готового шаблона.
- Указывать необходимые даты.
- Вводить ID эксперимента.
- Самостоятельно получать данные по интересующему A/B-тесту.

Решение снизило зависимость команды от аналитика при подготовке типовой отчётности.

### 3. Документирование целей, метрик и событий (менее техническая, для остальных членов команды)

**Инициатива:** самостоятельная.

Внедрила документирование настроенных целей, метрик и событий, чтобы:
- Сохранять информацию о реализованном трекинге.
- Обеспечить прозрачность настроек аналитики для команды.
- Упростить мониторинг корректности сбора данных.
- Предотвратить дублирование задач по настройке событий.

### 4. Аналитический аудит при онбординге новых клиентов

**Инициатива:** совместное решение с коллегой, самостоятельно разработанная методология и документация.

Разработала чек-лист аналитического аудита и шаблон клиентского отчёта, которые использовались при онбординге новых клиентов.

Аудит включал:
- Проверку конфигурации GA4 и GTM.
- Проверку корректности сбора данных.
- Выявление отсутствующих событий взаимодействия пользователей с сайтом.
- Подготовку рекомендаций по дополнительным GTM-триггерам и событиям.

Также проводила анализ исторического поведения пользователей с использованием:
- Исторических данных GA4.
- Воронок конверсии.
- Тепловых карт.
- Сегментации по устройствам и источникам трафика.
- Анализа популярных страниц и посадочных страниц.
- Анализа взаимодействия пользователей с отдельными элементами страниц.

На основании результатов аудита готовила рекомендации по настройке дополнительного трекинга и дальнейшему анализу пользовательского поведения.

Полученные данные впоследствии использовались для поиска возможностей тестирования и формирования первых 90-дневных планов A/B-тестирования.

### 5. Приоритизация экспериментов

На начальном этапе самостоятельно участвовала в приоритизации гипотез на основании аналитических данных и результатов исследований.

В дальнейшем часть ответственности за приоритизацию перешла к проектным менеджерам. Также в процессе участвовали клиенты, которые могли согласовывать или отклонять предложенные эксперименты.

Приоритеты тестирования пересматривались с учётом результатов экспериментов и новых аналитических данных.

## Самостоятельность и взаимодействие с командой

- Самостоятельно выявляла возможности для улучшения аналитических процессов.
- Ставила квартальные цели и информировала коллег и руководителя о планируемых инициативах.
- Самостоятельно разрабатывала и внедряла часть решений.
- Делегировала отдельные задачи коллегам, когда это требовалось.
- Создавала инструменты и документацию, которыми впоследствии самостоятельно пользовались другие аналитики и проектные менеджеры.
